**HackOrbit 2025** is a state-of-the-art hackathon landing page reimagined for the celestial frontier. Meticulously designed for a national-level competition, this project combines high-end aesthetics with immersive, interactive frontend engineering to provide a premium experience for hackers and innovators alike.

---

## ✨ Key Features

### 🛸 Interactive Visual Experience
- **Cosmic Aurora Engine**: A high-performance background system featuring animated, opaque light blurs that move organically. Includes a **Cursor Aurora Follower** that tracks your movement in real-time.
- **Premium Glassmorphism**: Every UI component utilizes advanced `backdrop-blur` filters, semi-transparent surfaces, and illuminated "glass-edge" borders for a sense of depth and translucency.
- **Bespoke Orbital Cursor**: A custom-coded dual-element cursor (Dot & Lagging Ring) that provides tactile visual feedback when hovering over interactive elements.
- **tsParticles Integration**: A subtle layer of floating cosmic dust particles that deepens the galactic atmosphere.

### 🛠️ Functional Components
- **Dynamic Countdown**: A live JavaScript-powered timer tracking the exact time remaining until the grand launch.
- **3D Flip Theme Cards**: Innovation tracks (AI, Web3, Fintech, etc.) are showcased via multi-dimensional cards with polished 3D flip animations and custom icons.
- **Live Interactive Timeline**: An automated roadmap powered by AOS (Animate On Scroll) that highlights the current stage of the event (Upcoming, Live, or Completed) based on real-time data.
- **Searchable FAQ**: A sleek, accordion-style interface with instant real-time search filtering for quick query resolution.
- **Futuristic Preloader**: A bespoke orbital ring SVG/CSS animation that ensures a premium first impression during site load.

---

## 🚀 Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Utility-first framework)
- **Animations**: [AOS.js](https://michalsnik.github.io/aos/) (Scroll reveals), Tailwind Keyframes
- **Particles**: [tsParticles](https://particles.js.org/) (Cosmic dust effects)
- **Typography**: [Google Fonts](https://fonts.google.com/) (Space Grotesk & Inter)
- **Icons**: [Google Material Symbols](https://fonts.google.com/icons)

## 🛠️ Installation & Setup

Since this is a frontend-focused project, no complex server setup is required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Satvikjoshi17/D-Coders.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd hackorbit-2026
   ```
3. **Open the project:**
   Simply open `hckthon.html` in any modern web browser to view the site.
